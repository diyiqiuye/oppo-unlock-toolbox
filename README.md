给 OPPO Find X5 Pro / Find X6 Pro 用的解锁与临时 root 图形化工具箱。

A GUI toolbox for unlocking & temp-rooting OPPO Find X5/X6 Pro (ColorOS 14).

Releases 里下载安装包或免安装 exe，连上手机后按界面 1 → 7 顺序执行。
